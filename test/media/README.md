# Исходники медиатеки

Вложенные папки содержат 9 демонстрационных записей в 5 файлах `media.json`.
Все URL на `example.com` условные и предназначены только для проверки структуры данных.
Это не реальные записи общины. Перед наполнением замените или удалите эти примеры.

В этой папке и любых вложенных папках можно размещать `media.json`.
Общие поля находятся в корне объекта; записи — в массиве `items`.
Любое поле записи переопределяет общее, даже если это `null`, пустая строка или пустой массив.
Если собственного `url` нет, общий `url` дополняется `/id` записи.
Для такого URL у записи должен быть непустой строковый `id`.

```json
{
  "type": "audio",
  "source": "s3",
  "url": "https://example.com/audio",
  "tags": ["torah"],
  "playlists": ["example"],
  "items": [{ "id": "lesson-01", "title": "Урок 1" }]
}
```

GitHub Action теперь собирает основную папку `media/` в `data/media.js`.
Тестовые примеры сохраняются здесь; для них можно запустить сборку вручную.
В нём объект с `items`, `playlists: [{id, count}]`, `tags: [{tag, count}]`.
Повтор одного тега или плейлиста внутри записи не увеличивает счётчик.
Удаление исходного файла также обновляет результат. Ошибка JSON прерывает сборку.
Результат вручную не редактируем. Счётчики в `media-groups.js` обновляются автоматически:
для каждой рубрики используется количество записей с тегом, равным её `id`.
Если такого тега нет, `count` становится 0. Названия, порядок и остальные поля рубрик сохраняются.

Локальная сборка из корня репозитория:

```sh
node scripts/build-media.mjs test/media test/data/media.js test/data/media-groups.js
```
